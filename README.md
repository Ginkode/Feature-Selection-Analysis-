# Autism Feature Selection Study

University statistical-analysis project on an autism-related dataset, focused on **how to choose among feature-selection approaches**, not just on applying them mechanically.

## What this project shows

The main value of the project is the statistical reasoning used to compare alternative selection strategies and decide which approach is more appropriate for the modelling goal.

The analysis discusses questions such as:

- which predictors contribute useful information;
- which variables are weak, redundant or unnecessary;
- how different selection approaches lead to different subsets of variables;
- when a simpler model is preferable to a larger one;
- how interpretability and statistical usefulness influence the final choice of method.

Rather than treating feature selection as a purely automatic step, the report emphasizes the **criteria used to justify one method over another** and the consequences of that choice for the final model.
